# Cross-portal WCAG contrast audit

This report is generated by the authenticated Playwright + axe-core CI job. It visits every administrator portal route at desktop (1280×900) and mobile (390×844), under both light and dark `prefers-color-scheme` settings.

- Rule: axe-core `color-contrast`
- WCAG AA thresholds: 4.5:1 for normal text; 3:1 for large text
- Text with effective opacity below 0.7 is listed separately.
- The “before” counts replay the legacy pale dark-theme text tokens on the light portal surfaces to reproduce the regression; “after” counts are measured against the actual shared-token implementation.
- CI fails if any post-fix color-contrast violations remain.

The authenticated emulator run replaces this file with per-page element evidence and appends the same report to the GitHub Actions step summary.

# IRPA-DBGS Windows desktop packaging

The Electron packaging toolchain is intentionally isolated from the root web application.

- `package.json` declares the pinned Electron and electron-builder development dependencies.
- `package-lock.json` is generated by `npm install` in this directory and committed by the Windows CI workflow.
- Windows CI verifies the generated lock with `npm ci --prefix desktop` before producing the NSIS installer.
- The Electron application loads the canonical Cloudflare production frontend; `electron/offline.html` is the local network-failure fallback.
- Packaging is build-only. CI does not publish a release or deploy the web application.

The Android Capacitor wrapper is generated from the root application's pinned Capacitor dependencies; there is no separately maintained Android npm package.

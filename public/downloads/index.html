IRPA Digital Governance

Official offline application downloads

Windows installer

For Windows 10 or later (64-bit).

Download Windows installer (.exe)

If Windows SmartScreen displays “Windows protected your PC”, verify that the publisher and checksum are as expected before choosing “More info”. The installer is not code-signed; Windows may show an unknown-publisher warning.

Android APK

Debug-signed APK. Minimum Android version: Android 7.0 (API 24), verified from the built APK manifest.

Download Android APK
  1. Download the APK on your Android device.
  2. Open the downloaded file.
  3. If prompted, allow your browser or file manager to install unknown apps.
  4. Review the installer prompt and tap Install.
  5. Open IRPA Digital Governance. The bundled app is designed to start offline after installation; online features still require connectivity.

iPhone and iPad

There is no native iOS IPA in this release. Use the web app as an installable web app (PWA):

  1. Open IRPA Digital Governance in Safari.
  2. Tap Share, then “Add to Home Screen”.
  3. Confirm the name and tap Add.
  4. Launch it from the Home Screen. Offline availability depends on previously cached app content and may be more limited than the Android package.

SHA-256 checksums

Verify downloaded files before installation. In PowerShell use Get-FileHash .\filename -Algorithm SHA256; on macOS/Linux use shasum -a 256 filename.
